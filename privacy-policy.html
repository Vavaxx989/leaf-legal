Privacy Policy

For Leaf — a Discord bot for Emergency Response: Liberty County (ER:LC) communities

Effective date: October 10, 2026

Important: This policy describes the practices reported by Leaf's operator. The API request fields, provider-side logging, server log retention, and any international transfers must be checked against the current code and each provider's documentation before this policy is treated as final.

1. Who operates Leaf

Leaf is operated by vavax989, an individual. For privacy questions or data requests, email vavax989larp@gmail.com.

2. Information Leaf handles

To provide its features, Leaf may process Discord identifiers and server configuration, including guild IDs, channel IDs, and role IDs; image links configured by server administrators; leave-of-absence (LOA) data; and punishment data. Depending on how a server uses Leaf, LOA and punishment records may relate to identifiable Discord users.

Leaf provides tickets, ER:LC API commands, player logs, server status, moderation and management tools, LOA features, welcome messages, reaction roles, staff-management features, and related utilities. Commands and interactions may be processed to respond to a request and operate these features.

3. Storage and API responses

Leaf uses JSON files for its own persistent configuration and records. It does not use a database. The JSON data identified above is stored on the Leaf operator's OVHcloud VPS hosted in France and remains there until it is manually deleted.

Leaf does not persist the responses it receives from the Bloxlink API, ER:LC API, or Roblox API. It processes those responses to provide the requested feature and relays relevant results in Discord embeds. This statement concerns Leaf's own storage; Discord and API providers may independently process or retain data under their own policies.

4. APIs and third-party services

Leaf uses the Discord API, Bloxlink API, ER:LC API, and Roblox API. Depending on the command or feature, requests may include identifiers or parameters needed to retrieve the requested account, game-server, player, or Discord-related information. The exact request fields sent to each API should be described here after being verified against Leaf's code; this policy does not assume that every API receives every category of data.

Discord processes messages, interactions, bot output, and other data under its own terms and privacy policy. Bloxlink, ER:LC-related API operators, and Roblox may receive request data and technical information such as request metadata or IP addresses according to their own systems and policies. Leaf's operator does not control those independent practices. Review the relevant provider policies before use.

Hosting provider: OVHcloud, VPS hosted in France. The VPS provider may process technical and operational data needed to provide and secure hosting, in accordance with its terms and applicable law.

5. Purposes and legal basis

Leaf processes configuration and command-related information to provide the bot's requested features, manage server settings and roles, operate LOA and punishment tools, respond to API commands, and maintain service security. Where the GDPR applies, the operator must identify and apply an appropriate legal basis for each processing activity. Depending on the feature and circumstances, this may include providing a requested service or legitimate interests in operating and securing Leaf. The specific legal basis should be confirmed for the actual implementation.

Providing certain configuration data may be necessary for the corresponding feature to work. If it is not provided, that feature may not function.

6. Logs and diagnostics

Leaf may generate error or diagnostic logs, and the hosting system may generate operational or security logs. The exact contents, location, access, and retention periods of these logs have not been specified in this policy and should be verified. Do not assume that logs contain no identifiers or request details without checking the bot and VPS configuration.

7. Retention and deletion

JSON configuration and records remain on the VPS until manually deleted. No automatic deletion period has been confirmed. To request access, correction, or deletion of information associated with Leaf, email vavax989larp@gmail.com and identify the relevant Discord server and data as clearly as possible. The operator may need reasonable information to verify and locate a request.

Removing Leaf from a Discord server does not, by itself, guarantee that its JSON files are deleted. The operator must manually remove relevant stored records. Any backups, server logs, or provider-held records may have separate retention periods that must be confirmed.

Access to the VPS is restricted to authorized users, and secrets are kept outside public source code. These are the security measures currently reported by the operator. No internet-connected system can be guaranteed completely secure. The operator should keep access credentials protected, limit permissions, and promptly address suspected unauthorized access.
